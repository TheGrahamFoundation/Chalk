# Chalk v0.0.1

First experimental public contract for Chalk.

## Included

- TypeScript semantic types for the initial Chalk document and element vocabulary
- `parseChalkSpec` validation boundary
- points, segments, lines, circles, polygons, angles, function graphs, text, and arcs
- renderer-independent structured mathematical intent
- usage documentation in `docs/USAGE.md`

## Status

Experimental. The format may change before v1.0.0. v0.0.1 establishes the semantic/parser boundary; a stable renderer API is not part of this release.
